# CodeAlpha Web Scraping & EDA

## Project Overview

This repository contains my completed projects for the CodeAlpha Internship Program in the field of Data Analytics.

The projects focus on collecting data from the web, preparing it for analysis, and performing Exploratory Data Analysis to discover patterns, trends, and potential issues within the dataset.

## Projects

### Task 1: Web Scraping
The first task focuses on collecting structured data from a public website using Python.

#### Tools & Libraries
- Python
- Requests
- BeautifulSoup
- Pandas

#### Main Activities
- Sent HTTP requests to a public webpage
- Parsed HTML content using BeautifulSoup
- Extracted relevant information from web pages
- Navigated through multiple pages
- Created a structured dataset
- Saved the collected data as a CSV file

#### Dataset

The project uses data collected from Books to Scrape, a website designed for web scraping practice.

The collected dataset contains information about books, including details such as:
- Book title
- Price
- Rating
- Availability

---

### Task 2 — Exploratory Data Analysis 
The second task focuses on exploring and understanding the dataset collected during Task 1.

#### Main Activities
- Asked meaningful questions about the dataset
- Examined the dataset structure
- Checked variables and data types
- Calculated descriptive statistics
- Investigated missing values and duplicates
- Visualized distributions and patterns
- Identified potential outliers
- Explored the relationship between book ratings and prices
- Performed statistical hypothesis testing
- Identified potential data-quality issues

#### Visualizations

The EDA includes visualizations such as:
- Book price distribution
- Price boxplot
- Rating distribution
- Rating vs. price scatter plot
